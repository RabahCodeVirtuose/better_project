GARAGE PAS PROPRE — SQUELETTE HTML / CSS / JS

Démarrage
1. Extraire entièrement le ZIP.
2. Ouvrir index.html dans un navigateur (double-clic).
Aucune installation, aucun framework, aucun abonnement nécessaire.

Fichiers
- index.html : structure et contenus, organisés en sections commentées.
- style.css : mise en page, couleurs et adaptations mobile/tablette.
- script.js : menu mobile et carrousel manuel.
- assets/ : images locales.

Couleurs : #110005, #570011, #FF0000, #FFFFFF.
Le rouge #FF0000 était fourni deux fois ; une seule variable suffit.
Modifier les variables au début de style.css pour changer la palette.

Fidélité et limites
La structure reprend Better_project.png. C'est une base éditable, pas un
export du fichier Figma ni une reproduction exacte de ses polices.
Les couleurs ont été adaptées à la palette demandée. Polices système.
Le logo et le fond forêt sont les fichiers fournis. Les autres visuels sont
des aperçus découpés de la maquette, donc leur qualité est limitée. Le fond
montagne conserve des éléments de la maquette : remplacer montagne.webp
par la vraie photo pour un résultat propre. Les chats sont statiques.
Les textes illisibles et les faux textes ont été remplacés par des contenus
de démonstration. Les coordonnées sont fictives. Carte statique.
La vidéo ne possède pas de source : ajouter par exemple dans la balise video :
<source src="assets/presentation.mp4" type="video/mp4">
Les réseaux sociaux sont un emplacement à personnaliser, pas de faux liens.
Les liens du menu mènent aux sections existantes de cette page.

À personnaliser
Rechercher les commentaires HTML pour trouver chaque section.
Remplacer les images dans assets en conservant leurs noms, ou modifier src.
Remplacer les textes, les adresses et les liens avant publication.
Ce squelette ne constitue pas un audit de conformité RGAA ou RGESN.
